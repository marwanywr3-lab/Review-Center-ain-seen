# عين سين — أداة إدارة واعتماد الأسئلة

موقع ويب بسيط يعمل محلياً في المتصفح بدون الحاجة لخادم أو قواعد بيانات خارجية.

## المميزات
- **رفع ملفات JSON**: استيراد الأسئلة وتنظيمها تلقائياً على شكل بطاقات.
- **حالة افتراضية (جارِ الاعتماد)**: جميع الأسئلة المرفوعة تدخل قسم «جارِ الاعتماد» أولاً.
- **تعديل كامل**: إمكانية تعديل رقم السؤال، التصنيف، نص السؤال، الخيارات، وتحديد الإجابة الصحيحة.
- **اعتماد وتصدير منفصل**: نقل الأسئلة المعتمدة لقسم «المعتمدة» وتصدير كل قسم في ملف JSON مستقل.
- **حفظ تلقائي + وضعان للمظهر**: حفظ التعديلات في `localStorage` مع دعم الوضع الفاتح والداكن.
